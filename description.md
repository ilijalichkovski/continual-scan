We are building a symbolic benchmark for compositional continual learning.

It is inspired by SCAN and COGS (and contains very similar problems), but the exact format should be similar to MLC (repo is here), which is based on this Nature article titled "Human-like systematic generalization through a meta-learning neural network": https://www.nature.com/articles/s41586-023-06668-3.
